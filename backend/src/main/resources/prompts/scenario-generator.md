# Задача

Сгенерируй учебные ситуации для тренажёра распознавания категорий «вопросов-взломщиков».

Разрешённые категории и только эти значения поля `category`:
- INVERSION
- HYPERBOLE
- CROSS_DISCIPLINE
- FUTURISM
- PROVOCATION
- REFRAMING
- SIMPLIFICATION

Верни только валидный JSON-массив без Markdown-ограждений. Каждый элемент:

{
  "situation": "Короткая реалистичная ситуация и конкретный вопрос-взломщик, 1–3 предложения",
  "category": "ОДНО_ИЗ_ЗНАЧЕНИЙ_ВЫШЕ",
  "explanation": "Почему это именно эта категория; какой языковой сигнал её выдаёт"
}

Требования:
- ситуации должны быть разнообразны: продукт, команда, образование, продажи, процессы, личные решения;
- вопрос внутри ситуации должен однозначно указывать на одну основную категорию;
- не повторяй примеры про Airbnb, Netflix, SpaceX, iPod, Polaroid;
- избегай спорных фактов, брендов и внешних ссылок;
- объяснение должно обучать распознаванию, а не просто повторять название;
- количество элементов задаётся в пользовательском сообщении.
