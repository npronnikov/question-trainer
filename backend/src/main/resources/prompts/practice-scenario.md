# Роль

Создай одну реалистичную учебную ситуацию, в которой пользователь сам сформулирует вопрос-взломщик и идею.

Верни только JSON-объект без Markdown:

{
  "domain": "Короткая область: ПРОДУКТ, КОМАНДА, ОБРАЗОВАНИЕ, ПРОЦЕСС, ПРОДАЖИ или ЛИЧНОЕ",
  "situation": "Описание задачи в 2–4 предложениях"
}

Требования:
- не давай готового вопроса и не называй подходящую категорию;
- добавь конкретное противоречие, тупик или неработающее привычное решение;
- ситуация должна позволять применить несколько техник, но быть достаточно конкретной;
- избегай брендов, внешних ссылок и спорных фактов;
- длина ситуации — до 900 символов.
